Setup erforderlich
OAuth2 ist noch nicht konfiguriert. Füge diese Variablen in deine .env ein:
# Discord Developer Portal → deine App → OAuth2
DISCORD_CLIENT_ID=deine_client_id
DISCORD_CLIENT_SECRET=dein_client_secret
DISCORD_REDIRECT_URI=http://localhost:5000/auth/callback
DASHBOARD_SECRET=irgendein_langer_zufallsstring
ADMIN_USER_IDS=deine_discord_user_id
So findest du deine Discord User ID:
Discord → Einstellungen → Erweitert → Entwicklermodus aktivieren
Dann: Rechtsklick auf deinen Namen → ID kopieren
OAuth2 App erstellen:
1. discord.com/developers/applications öffnen
2. "New Application" → Name eingeben
3. OAuth2 → Redirects → http://localhost:5000/auth/callback hinzufügen
4. Client ID + Secret kopieren und in .env eintragen

Nach dem Neustart des Dashboards erscheint hier der Login-Button.
